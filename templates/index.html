03

What the crew breathes

A physics model that turns NASA's smoke measurements into a dose in each part of the lung.

  1. NASA measured the smokeFor each overheated material, SAME recorded how many particles there are and how big. Smoke is a mix of sizes, mostly 0.05 to 0.5 µm.
  2. Smoke changes as it driftsParticles collide and stick, so there are fewer, larger ones. We fitted that rate to {{ aging.n_pairs }} fresh/aged SAME pairs. Diluted smoke ages slowly.
  3. Every size has a fateThe ICRP 66 lung model gives the chance a particle of each size sticks in each region. Big ones hit the nose and throat; tiny ones wander into the alveoli; those near 0.3 µm are mostly breathed back out.
  4. Gravity shifts itSettling under gravity matters for 0.5 to 3 µm particles. Without it, fewer of those deposit. Reduced gravity is shown as a band, not one number.

    04

    Will the flame survive?

    A machine-learning model trained on NASA's FLEX droplet burns. Set an atmosphere and it predicts how the flame behaves.

    How this model works
    • Trained on: {{ ml.rate_tests }} FLEX tests on the ISS, each a single droplet of methanol or heptane burned in a chosen gas mixture.
    • It predicts two things: the chance the flame goes out before the fuel is used up, and how fast the droplet burns.
    • How good is it: tested on whole test series it never saw. It ranks "goes out" versus "burns to the end" correctly {{ '%.0f' % (ml.extinction_auc * 100) }}% of the time (AUC), and predicts burning rate within {{ '%.2f' % ml.rate_mae_mm2_s }} mm²/s on average (R² {{ '%.2f' % ml.rate_r2 }}).
    • Limits: fuel droplets only, not solid materials, and only inside the tested conditions. In FLEX, {{ '%.0f' % (ml.share_that_went_out * 100) }}% of flames went out early, so high values are normal.
